# INSTAURIUS Portfolio — Recruiter-Demo

Ein kleines, öffentliches Demo-Repository für Bewerbungen um eine **Ausbildung zum Fachinformatiker für Anwendungsentwicklung**.

Das eigentliche INSTAURIUS-System bleibt privat. Dieses Repository zeigt einen kompakten Ausschnitt meiner Arbeitsweise: typisierte Logik, explizite Zustände, Tests und Dokumentation.

## Stack

- TypeScript
- Node.js
- Vitest
- Git / GitHub

## Was die Demo zeigt

Das Beispiel implementiert ein kleines Fail-Closed Decision Gate. Eine Entscheidung wird nur dann als `ALLOW` zurückgegeben, wenn die erforderlichen Nachweise vorhanden sind. Fehlende oder widersprüchliche Nachweise führen zu `UNKNOWN` oder `BLOCK`.

## Lokal starten

```bash
npm install
npm test
```

## Hauptprojekt

Mein privates Full-Stack-Projekt nutzt unter anderem Next.js, React, TypeScript, Prisma, Playwright und automatisierte QA.
